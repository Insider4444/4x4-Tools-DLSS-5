# Contributing

For bugs, include the release version, GPU, driver, Windows and Adobe versions, project resolution/bit depth, active preset and steps to reproduce. Describe whether the problem occurs during setup, project opening or rendering. Review logs for private paths before attaching them. Avoid uploading personal projects or licensed footage without permission.

Use docs/BUILDING.md for the local build. CPU finishing tests can run without proprietary SDKs; full host/GPU checks require the specified local dependencies and compatible hardware. Describe validation and visual/compatibility consequences in a pull request. Preserve Adobe parameter disk IDs and existing saved-project behavior.

Do not commit SDKs, model binaries, credentials, private footage, application projects, caches or build outputs. Runtime changes need explicit provenance, applicable distribution rights and hardware validation. Avoid presenting untested GPU generations as supported.
