# Security reports

Do not put credentials, private footage or sensitive logs into a public issue. For a suspected security vulnerability, use GitHub's private vulnerability reporting when it is enabled for this repository. Otherwise contact the repository owner through a private channel before disclosing exploit details publicly.

Use release checksums and obtain packages from this repository. v1.0 installers are not Authenticode-signed. The included model runtime is a separately licensed, community-modified binary, identified by hash in THIRD-PARTY-NOTICES.md. The installer checks package integrity and GPU processing; those checks do not constitute a security audit of a closed-source runtime.
